\section*{Data and method}
\begin{itemize}
  \item \textbf{Sample.} The 307 IE schools, one per cluster: Transport 102,
        Double shift 102, Comparison 103.
  \item \textbf{Data.} RTSM school surveys: 127 schools from the Fall 2025
        pre-assessment and 180 from the February--May 2026 field validation.
        Each school appears in exactly one round. Only questions asked in both
        rounds, with the same wording, units and skip logic, are used
        (57 variables).
  \item \textbf{Estimation.} Tables are produced with \texttt{iebaltab}. Group
        columns show the mean with its standard error in parentheses. The
        difference is the raw difference in means; significance stars come from
        an OLS regression of the variable on the pair dummy with tehsil fixed
        effects and robust standard errors (one IE school per cluster, so these
        equal standard errors clustered by cluster).
        * $p<0.10$, ** $p<0.05$, *** $p<0.01$.
  \item \textbf{Comparisons.} Table set 1 compares all IE schools across the
        three arms. Transport IE schools are all girls' or co-ed schools and
        Double-shift IE schools are all boys' schools, so set 1 shows
        differences in gendered variables by design. Sets 2 and 3 compare
        schools of the same type: Transport vs girls' and co-ed Comparison
        schools, and Double shift vs boys' Comparison schools.
  \item \textbf{Joint test.} The last table of each set reports, for each
        comparison, the p-value of an F-test that 26 variables (those with no
        missing values and no exact linear dependence) jointly predict the arm.
\end{itemize}
